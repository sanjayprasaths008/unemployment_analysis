# unemployment_analysis
# Unemployment Analysis in India

## Overview
This project analyzes unemployment trends in India using datasets:
- `Unemployment in India.csv`
- `Unemployment_Rate_upto_11_2020.csv`

The analysis focuses on:
- Cleaning and merging raw data
- Exploring unemployment rates across regions
- Visualizing unemployment trends
- Studying the impact of COVID‑19 lockdowns
- Identifying seasonal patterns

---

## Features
- Cleans inconsistent headers and merges multiple datasets
- Provides statistical summaries of unemployment, employment, and labour participation
- Generates visualizations:
  - Line plot of unemployment trends by region
  - Bar chart showing COVID‑19 impact (Apr–Jun 2020)
  - Line plot of average monthly unemployment trends
- Highlights insights such as:
  - Sharp spikes during COVID lockdowns (Apr–May 2020)
  - Regional disparities (Tripura, Haryana, Jharkhand, Bihar had extreme unemployment >40%)
  - Seasonal variations in unemployment
